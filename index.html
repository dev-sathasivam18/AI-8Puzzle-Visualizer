Introduction to the 8-Puzzle problem

The 8-Puzzle is a sliding-tile puzzle played on a 3 × 3 board. Eight tiles numbered 1–8 and one empty space (the blank) fill the nine cells. A move slides a tile that is next to the blank into it — or, equivalently, moves the blank up, down, left or right. The goal is to turn a given initial state into a given goal state using as few (or as cheap) moves as possible.

It is a classic example of a state-space search problem:

  • States — every arrangement of the tiles (9! = 362,880, of which exactly half, 181,440, are reachable from any given state).
  • Initial / goal state — chosen by the user.
  • Actions — move the blank Up, Down, Left or Right (2 to 4 legal moves per state).
  • Transition model — swap the blank with the neighbouring tile.
  • Path cost — each move costs 1 (this app can also charge a move the number on the tile it moves).

Not every puzzle can be solved: the goal is reachable only if the initial and goal boards have the same inversion parity. The app checks this and reports unsolvable puzzles as Not Found.

About this project

This web app implements Uniform Cost Search from scratch in JavaScript and shows, step by step, how it explores the state space: which node is expanded, what its successors are, and how the frontier and explored lists change.

What you can do

  • Enter your own puzzle or generate a random solvable one
  • Run, pause, resume, step forwards / backwards and change the speed
  • Watch the blank tile slide along the final solution path
  • Compare UCS with BFS, DFS, DLS, IDDLS, GBFS and A*

Built with HTML5, CSS3, JavaScript (ES6) and Bootstrap 5.
